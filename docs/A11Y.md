# Accessibility (A11Y)

## Compliance
- **Standard:** WCAG 2.2 AA
- **Current Status:** Bootstrap compliant

## Implemented
- [x] Skip link to main content
- [x] Semantic HTML landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`)
- [x] Single `<h1>` per page
- [x] Proper form labels with `htmlFor`
- [x] ARIA attributes (`aria-label`, `aria-labelledby`, `aria-pressed`, `aria-live`)
- [x] Keyboard navigable controls
- [x] Screen reader only text (`.sr-only`) for context

## Testing
- Tested with `@testing-library/react` and user events
- Axe-core compliance planned for later phases

## P1 additions
- [x] Native `<fieldset>`/`<legend>` for additional context toggles
- [x] `<table>` with `<caption>` and column headers for the run-of-show
- [x] Text status labels for tasks and risks, never colour alone
- [x] Native `<details>`/`<summary>` for vendor checklists with a 44 px summary target
- [x] Budget health and infeasibility announced in an `aria-live="polite"` dashboard region with a `role="alert"` alert
- [x] Form controls keep visible labels and 44 px minimum target height
